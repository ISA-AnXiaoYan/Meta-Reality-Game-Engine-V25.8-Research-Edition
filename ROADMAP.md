# Public roadmap

<!-- SPDX-License-Identifier: AGPL-3.0-only -->

## 0.2 research foundation

- Stable synthetic quick start, Contracts, Replay, Geometry Profiles, preview/filter examples and reproducible checks.
- V25.8–V26 historical archive with provenance, data boundary and static V26 knowledge graph.
- Contributor-facing governance, release metadata and CI hygiene.

## Next public milestones

1. Expand synthetic and recorded-fact examples without importing private hardware dependencies.
2. Add schema evolution fixtures and compatibility reports.
3. Improve cross-platform graph launch and offline documentation packaging.
4. Publish V1.0 architecture snapshots only when they can be clearly marked as roadmap material.

## Explicitly out of scope

- Shipping vendor SDKs, proprietary binaries, model weights or credentials.
- Claiming field qualification, production Authority, certified safety or official match adjudication.
- Using public historical records to infer personal identity or train biometric/re-identification systems.
