# Governance

<!-- SPDX-License-Identifier: AGPL-3.0-only -->

## Scope

This repository is a public research project and historical archive. It does not grant production Authority, event-operation authority, safety certification, or field qualification.

## Roles

- Maintainer: defines supported surfaces, reviews archive changes, manages releases and security response.
- Contributor: submits reproducible changes within the public contracts and license boundaries.
- User/operator of a downstream project: remains responsible for hardware, venue, rules, privacy, safety and any production qualification.

## Decision records

Changes that affect public contracts, licenses, data policy, archive provenance, supported versions, or release claims require a documented decision in a pull request or release note. Candidate, shadow, qualified and production states must remain separate.

## Archive rule

Historical files are frozen reference material. Corrections are limited to provenance, security, license, privacy, link repair, or an explicitly documented archival correction. They are not a substitute for the active research package.

## Contribution rights

The repository currently uses the Contributor License Agreement in [CLA.md](CLA.md). A contribution is accepted only when the contributor confirms the CLA statement in the pull request template.

## Conduct and security

Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Report vulnerabilities through [SECURITY.md](SECURITY.md), not public issues.
