# Pre-V27 original-code rollout

<!-- SPDX-License-Identifier: AGPL-3.0-only -->

本轮扩展将 V27 之前的原创代码和算法作为审计范围，采用 hash-only provenance、逐文件分类、clean-room 重实现和支线 profile 的方式逐批公开。

已公开的第一批能力：

- Replay/Contracts、合成 2/8 路样例和故障注入；
- V26 公共 Recording/Polygon/IR-ID schema；
- Null/Protocol 边界；
- Event/Polygon/稀疏预览 clean-room 算法；
- GeometryProfile、foot-point 和 inward-four-sensor 变体。

尚未公开：来源不明、许可证不清、真实 SDK/数据/权重、私有运行归档，以及未通过 G8 逐文件复核的历史实现。
