# Release policy

<!-- SPDX-License-Identifier: AGPL-3.0-only -->

A public research release requires:

1. Clean Git worktree and a recorded source commit.
2. Passing tests, Markdown link checks, governance metadata checks and R6 hygiene checks.
3. Updated CHANGELOG, citation, provenance, SBOM scope and known limitations.
4. A tag and GitHub Release with release notes and checksums where artifacts exist.
5. No claim that a green CI run implies production qualification, field effectiveness or Authority.

R6 means repository-release readiness only. It does not establish hardware quality, safety certification, competition referee validity or a production cutover.
