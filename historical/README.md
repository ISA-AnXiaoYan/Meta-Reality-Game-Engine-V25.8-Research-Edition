# V25.8–V26 historical archive

<!-- SPDX-License-Identifier: AGPL-3.0-only -->

This directory is the source-bearing historical archive for the public research edition.

- v25.8/ preserves eligible V25.8 source, research records, runtime material, releases and legacy deployment code.
- v26/ preserves the V26 checkout at its recorded Git commit, including deployment scripts and research configuration.
- The source trees are historical evidence, not a claim that any service is safe to start or qualified for production use.

New development begins in src/mrge/, contracts/, replay/ and examples/. The archive is read-only by default.

The maintainer has declared public-release authority for material imported here. Files excluded because they remain proprietary, third-party, binary-only, credential-bearing, or otherwise unauthorized are recorded in [EXCLUSIONS.md](EXCLUSIONS.md). The archive deliberately does not substitute a hash inventory for source: approved material is present as files in the repository.

Licensing follows the repository root unless a retained file contains a more specific valid license notice. Vendor SDKs, model weights and other third-party redistributables are not mirrored; an integration source file may reference an external dependency without embedding it.

Read [SUPPORT_STATUS.md](SUPPORT_STATUS.md), [DATA_CATALOG.md](DATA_CATALOG.md), [LICENSE_AUDIT.json](LICENSE_AUDIT.json), [EXCLUSIONS.md](EXCLUSIONS.md) and [RELEASE_MANIFEST.json](RELEASE_MANIFEST.json) before using archive material.
